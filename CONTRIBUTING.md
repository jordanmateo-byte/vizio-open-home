# Contribuir

Abre un issue con modelo, plataforma y firmware, pero no con el número de serie, PIN, token, SSID o configuración completa. Distingue «la API aceptó», «cargó el catálogo» y «reprodujo contenido».

Prueba los cambios de interfaz con `npm test` y, cuando sea posible, en una TV compatible usando USB antes de escribir la copia interna. Para nuevos modelos, aporta evidencia de raíz, montajes, respaldo, Home, encendido, HDMI y volumen. No marques el modelo como compatible por similitud del nombre.

Los cambios de instalación deben mantener la separación entre preparar, copiar, verificar y cambiar Home. No añadas borrados generales, flasheo o servicios permanentes al flujo normal. Conserva los avisos y créditos de terceros.
