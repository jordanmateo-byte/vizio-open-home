# Seguridad y límites

Este proyecto documenta ejecución root por USB en una TV del propietario. La biblioteca y las herramientas no deben exponerse a Internet. Mantén las claves y respaldos fuera de issues y repositorios.

Los reportes públicos de problemas no deben incluir exploits dirigidos a TVs ajenas, tokens, claves del fabricante o configuración privada. Si encuentras un fallo del launcher, describe primero la causa y el alcance sin datos personales. Las vulnerabilidades nuevas del firmware deben coordinarse con el fabricante; este repositorio no sustituye ese proceso.

No se instaló una shell persistente en la unidad de referencia. Desactivar el puente y restaurar Home no parchea el firmware vulnerable del proveedor. La compatibilidad y recuperación se limitan a lo que documentan las pruebas del dispositivo de referencia.
