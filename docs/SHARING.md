# Presentación, búsqueda y redes sociales

## Nombre y descripción del repositorio

Nombre: `vizio-open-home`

Descripción de GitHub:

Launcher local para Vizio SmartCast bloqueado por región: Home y arranque sin PC, USB ni Fire Stick. Probado en M657-G0; instalación y restauración documentadas.

Temas: `vizio`, `smartcast`, `launcher`, `linux`, `smart-tv`, `mexico`, `javascript`, `html`, `home-screen`, `usb`, `root`.

No usar etiquetas Android, APK o WatchFree desbloqueado: describirían otro resultado.

## Título para compartir

Mi Vizio decía «no disponible en tu región». Ahora tiene su propio launcher, sin PC ni Fire Stick.

## Texto para redes

La TV funcionaba, pero VIZIO Home estaba bloqueado en México. Creamos Vizio Open Home: un inicio local con apps, biblioteca, reordenación, entradas y arranque automático desde la memoria de la TV. Home, HDMI y volumen siguen funcionando.

Es SmartCast sobre Linux, no Android. Documentamos el acceso root, los respaldos, el puente USB y cómo revertir los cambios. Probado en una M657-G0 con firmware 7.0.120.1-1: otros modelos necesitan validación. No desbloquea WatchFree+ ni los catálogos regionales de las apps.

Código, antes/después e instrucciones: https://github.com/jordanmateo-byte/vizio-open-home

## Dónde va cada cosa

El README explica el problema con sus palabras exactas, presenta el antes/después y enlaza las instrucciones. La descripción y los temas se configuran en GitHub. El título más narrativo se usa al compartir el enlace; no hace falta cambiar el nombre del proyecto ni añadir textos promocionales al launcher de la TV.

El repositorio público puede aparecer en Google, pero no se garantiza indexación, posición ni el texto mostrado. GitHub controla el HTML de sus páginas: añadir etiquetas meta en el README no configura sus títulos ni Open Graph. Una página web del proyecto sería otra publicación y no es necesaria para compartir el repositorio.

Fuentes: [títulos descriptivos en Google](https://developers.google.com/search/docs/appearance/title-link), [temas de GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics), [vista previa social de GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repositorys-social-media-preview).
